Privacy Policy

Last Updated: October 2026

1. Overview

X-Ray Runtime Inspector is a developer debugging tool for tracing Python algorithms and data structures.

2. Code Execution and Sandboxing

In public and production deployments, submitted Python code is evaluated inside ephemeral, containerized sandbox environments (e.g., Judge0 CE). Neither user-submitted scripts nor execution traces are stored permanently on server disks or retained in persistent databases.

3. Data Collection

X-Ray does not require account registration, does not collect personal identifiers, and does not use tracking cookies or third-party analytics scripts.

4. Rate Limiting and Network Security

Volatile in-memory rate limiting is applied to prevent denial of service and free-tier quota exhaustion. Network egress from the code execution sandbox is restricted.
