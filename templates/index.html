Concept Glossary

Variable

A named memory location that stores a value. In Python, variables are dynamically typed references bound to objects in local or global scope.

Loop & Iteration

A control flow construct (for, while) executing a block of statements repeatedly until a termination condition is reached.

Sequence & List

An ordered collection of elements accessible via zero-based integer indices. Illustrated in Code X-Ray as distinct memory blocks with active pointer markers.

Pointer / Index Marker

An integer variable holding an offset indexing a position in a sequence (e.g. left, right, mid, i, j).

Swap

Exchanging the values of two variables or sequence positions (e.g. a[i], a[j] = a[j], a[i]), animated in X-Ray via projectile motion.

Comparison

Evaluating relational operators (<, >, ==, !=, <=, >=) between two elements or expressions, highlighted in amber during trace steps.

Recursion & Call Stack

A function invoking itself on smaller subproblems until a base condition stops the descent. Each call allocates a stack frame in execution memory.

2D Matrix / Grid

A rectangular array of elements arranged in rows and columns accessed via grid[r][c], visualized in X-Ray's adaptive coordinate stage.

Time Complexity (Big-O)

The theoretical upper bound rate of step growth as input size n approaches infinity. E.g. O(1) constant, O(log n) logarithmic, O(n) linear, O(n^2) quadratic.

Auxiliary Space Complexity

The amount of additional memory allocated by an algorithm beyond the storage required for the input data itself.
